# Taller de Recursividad - Estructuras de Datos

**Estudiante:** Anyi Daniela Pérez Castillo

## Descripción del taller
Taller de Estructuras de Datos en Java con 14 ejercicios, todos resueltos
mediante funciones recursivas (cada una con su caso base): factorial, inversión
de un número, sumatorias, suma de dígitos, potencia, M.C.D. (algoritmo de
Euclides), copia de cadenas, cociente y multiplicación con operaciones
sucesivas, suma de un vector y de una matriz, serie de Fibonacci y función
de Ackermann.

## Instrucciones para ejecutar el programa
1. Clonar el repositorio: `git clone https://github.com/adperez-lab/Taller-Recursividad.git`
2. Abrir el proyecto en NetBeans (File > Open Project).
3. En `src/Recursividad/` elegir la clase del ejercicio que se quiere probar
   (por ejemplo `Ejercicio01Factorial.java`).
4. Clic derecho sobre la clase > Run File (Shift + F6).
5. Ingresar los datos que pida el programa por consola.
